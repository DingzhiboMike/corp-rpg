# Пакеты ролей — как пользоваться

Роль игрока определяет, из какого пакета брать центральную проблему,
часть NPC и твисты. Общий банк (`world/banks.md`) — компании, общие
NPC, источники кризиса — работает поверх любого пакета.

Как пользоваться:
1. Найди пакет по роли игрока. Нет точного — возьми ближайший (см.
   «Своя роль» в конце) и адаптируй.
2. Центральную проблему выбирай по тегу компетенции: в полной настройке —
   под цель обучения, в быстром входе — любую, которую этот игрок ещё не
   видел.
3. Хотя бы один сквозной NPC — из пакета роли. Второй можно из общего
   банка: столкновение с человеком из чужой функции даёт лучшие сцены.
4. Словарь роли — не для того, чтобы им щеголять. Вставляй 2–3 слова или
   фразы за сессию в реплики NPC, чтобы игрок узнал свою работу.
5. Твисты пакета — в дополнение к общей колоде, по тем же правилам
   (сначала проверь, не растёт ли твист из флажка «Хроники»).
