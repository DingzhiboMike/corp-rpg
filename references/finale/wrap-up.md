# Финал сессии

ФИНАЛ (дольше в режиме «одним блоком» — см. ниже): путь команды,
2 альтернативных развития, итог по мотивации и активам, второе (финальное)
«Зеркало», закрывающий ритуал «Ставка сделана», титулы и **карточка сессии**
— короткий блок, которым игроку захочется поделиться (формат —
`references/finale/debrief-scoring.md`, «Карточка сессии»). Карточка — последнее
в игровом финале, в любом режиме; карточка для фасилитатора идёт после неё.

Чтобы собрать карточку, копи по ходу сессии про себя: сколько раз игрок
поставил Ва-банк, сколько дебафов получил и закрыл, и одну самую сильную
реплику игрока — его собственными словами.

Если игрок выбрал рефлексию **одним блоком** — перед остальным финалом
разверни консолидированный разбор по заметкам, которые копил по ходу сцен:
2–4 сцены, для каждой — какой был выбор и что он показал, живым текстом,
не таблицей. Это тот момент, где глубина, которую пропустили по ходу
действия, возвращается разом.

Для менторских/тренинговых сессий — после игрового финала:
1. Предложи короткую **карточку для фасилитатора**, см.
   `references/finale/debrief-scoring.md`.
2. Спроси про **Перенос-обязательство** — одно конкретное действие в
   реальной работе на ближайшие 48 часов, которое перекликается с тем, что
   игрок делал в сессии. Не придумывай его сам — предложи, оттолкнувшись
   от конкретной сцены, но финальную формулировку берёт игрок. Зафиксируй его в Досье игрока
   (в переписке, не во внешнем файле) для следующей сессии — формат в
   `references/modes/continuity.md`.
